# プライバシーポリシー

**最終改定日:** 2026年10月15日

本プライバシーポリシーは、[jp.mikkiki](https://play.google.com/store/apps/developer?id=jpmikkiki)（以下「当開発者」）がGoogle Playストア等で配信するすべてのアプリケーション（以下「本アプリ」）における、利用者情報の取り扱いについて定めたものです。

---

## 1. 収集する情報とその取得方法

当開発者のアプリでは、機能の提供および品質向上のために以下の情報を取得・利用する場合があります。アプリによって取得する項目は異なります。

### (1) すべてまたは一部のアプリで取得する共通情報
* **利用状況・統計データ:** アプリの利用状況や画面遷移などの利用傾向（Firebase Analytics等）。これらは個人を直接特定しない統計情報として収集されます。
* **クラッシュ・診断情報:** アプリの障害・クラッシュ時のスタックトレース、OSバージョン、デバイスモデル、メモリ状態等の診断情報（Firebase Crashlytics等）。

### (2) アカウント認証・クラウド保管・課金機能を持つアプリ（「MP4DRIVE」等）で取得する情報
* **アカウント認証情報:** Googleサインイン時に取得されるユーザー識別子（UID）、メールアドレス、表示名等（Firebase Authenticationを利用）。
* **ユーザーメディアデータおよびメタデータ:** 利用者が明示的に保存・バックアップ・同期を選択した動画・写真データ（原本）、プレビュー用サムネイル画像、およびファイル名・撮影日時・ファイルサイズ・ハッシュ値（SHA-256）等のメタデータ。
* **暗号化鍵のバックアップデータ:** 機種変更時等のデータ復元を目的として利用者が明示的に許可した場合に限り、利用者のGoogle Drive内にある本アプリ専用の隠しデータ領域（`appDataFolder`）に暗号化鍵データを保存・照合します（※他のファイルへのアクセスは行いません）。
* **購入・サブスクリプション情報:** Google Play Billingを介して処理される注文ID、購入トークン、定期購入プランの契約状態、有効期限情報。なお、クレジットカード番号等の決済情報はGoogle Play側で安全に処理され、当開発者が直接取得・保持することはありません。

## 2. 利用目的

収集した情報は、以下の目的のためにのみ利用します。

1. 本アプリの基本機能の提供（ユーザー認証、クラウドへのデータ暗号化保管、一覧表示、端末への原本復元等）
2. 契約容量の管理、定期購入プランの有効化・ライセンス照合
3. 機種変更や再インストール時のデータおよび鍵の復元
4. 不正利用の防止および正規アクセスの検証（Firebase App Check / Play Integrity）
5. アプリの不具合調査、障害対応、パフォーマンス改善
6. 利用者からのお問い合わせへの対応

## 3. 外部送信および第三者提供

本アプリでは、上記の利用目的を達成するため、Google LLCが提供する以下の信頼できるクラウド基盤および外部サービスを利用し、通信およびデータ保管を委託しています。法令に基づく開示要請がある場合を除き、これら委託先以外の第三者へ個人情報を販売・提供することはありません。

* **Google Cloud / Firebase**（Authentication, Cloud Firestore, Cloud Storage, Cloud Functions, App Check, Crashlytics, Analytics）
* **Google Play Billing**（アプリ内課金・定期購入処理）
* **Google Drive API**（アプリ専用領域への鍵バックアップ）

## 4. 安全管理措置（セキュリティ）

当開発者は、利用者データの漏洩、滅失または毀損を防止するため、適切なセキュリティ措置を講じています。

* **通信の暗号化:** すべての通信はHTTPS/TLSにより暗号化されます。
* **端末内暗号化:** クラウドへ保存される動画データは、端末上でAES-256-GCM暗号化が行われた上で送信・保管されます。
* **鍵の保護:** 暗号化鍵はAndroid Keystoreで保護され、クラウド同期時もGoogle Driveのセキュアなアプリ専用領域に保管されます。
* **不正アクセスの防止:** サーバー側のAPIアクセスにはFirebase App Check等を導入し、正規アプリ以外からのリクエストを遮断しています。

## 5. データの保持期間および削除（アカウント削除手続き）

利用者は、保存したデータおよびアカウントをいつでも削除できます。

1. **個別データの削除:**
   アプリ内からクラウド上の保管データをいつでも個別に削除できます。
2. **アカウントおよび保管データの一括削除:**
   専用Webページまたはアプリ内の設定画面より、Googleアカウントで本人確認を行うことで、アカウント・保管データ・メタデータを即時に一元削除できます。
   * 削除されたクラウドデータは、障害復旧用のSoft Deleteとして最大7日間保持された後、完全に消去されます。
3. **定期購入の解約に関する注意:**
   アカウントやアプリ内データを削除しても、Google Playの定期購入は自動的に解約されません。Google Playアプリの「お支払いと定期購入」より、ご自身で定期購入の解約手続きを行ってください。
